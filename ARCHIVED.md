# Archived herbivoreTTR Repository

This repository is the private, read-only legacy record of herbivoreTTR. Its
final snapshot is identified by annotated tag `legacy-final-2026-07-16`.

Active development continues in the unrelated private replacement repository
`BWBrook/herbivoreTTR`. Legacy R and C++ behavior is retained as historical
evidence, not as scientific or architectural authority for the rebuild.

The deleted generated Goal 004 bundles and scratch-agent traces were
deliberately excluded from this archive.
