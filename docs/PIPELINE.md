# HerbivoreTTR Pipeline Overview

This document summarises the `_targets.R` pipeline and highlights key artefacts.

## Execution Profile
- Deterministic seed via `tar_option_set(seed = 1L)`.
- Targets store objects as compressed RDS (`format = "rds"`), with transient memory to keep the pipeline lightweight.
- All functions are sourced from `R/` using `targets::tar_source("R")`.
- Canonical artefacts are emitted to `artefacts/canonical_runs/smoke_v0/` through `canonical_bundle_files`.

## Target Graph (DAG)

1. `canonical_seed` → fixed scalar seed (`1L`) for canonical smoke runs.
2. `canonical_scenario_slug` → canonical scenario id (`"smoke_v0"`).
3. `conditions` → daily environmental series generated by `init_conditions(mode = "flat")`.
4. `plants0` → initial plant state from `init_plants(veg_types = c(0, 1, 2))`.
5. `herb0` → initial herbivore state from `init_herbivore(mass = 5e5)`.
6. `day_after_spinup` → integer offset derived from `CONSTANTS$SPIN_UP_LENGTH`.
7. `canonical_scenario_parameters` → named parameter list for manifest hashing.
8. `sim_day1` → runs `run_daily_herbivore_simulation()` for first post-spinup day with fixed seed.
9. `plants_day1_csv` → writes day-1 plant snapshot CSV to `data/outputs/`.
10. `herb_day1_csv` → writes day-1 herbivore snapshot CSV to `data/outputs/`.
11. `sim_day3_demo` → runs `run_herbivore_days()` for three post-spinup days.
12. `sim_day7` → runs `run_herbivore_days()` for seven post-spinup days.
13. `plants_day7_csv` → writes day-7 plant snapshot CSV to `data/outputs/`.
14. `herb_day7_csv` → writes day-7 herbivore snapshot CSV to `data/outputs/`.
15. `canonical_bundle_files` → copies required CSV outputs to canonical artefact folder and writes `run_manifest.json`.

## Notes
- CSV outputs are marked as `"file"` targets so downstream analyses can depend on them explicitly.
- The canonical bundle target (`canonical_bundle_files`) is also a `"file"` target and forms the smoke artefact contract consumed by CI and tests.
- The pipeline currently skips execution when artefacts exist; run `targets::tar_destroy()` or delete files in `_targets/` to force recomputation.
- Future expansions should add new targets under the corresponding sections above and update this document accordingly.
