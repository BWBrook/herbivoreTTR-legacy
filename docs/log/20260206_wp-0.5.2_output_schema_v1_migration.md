# WP-0.5.2 — Output schema v1 migration: run_id/herbivore_id + migration tests

## What changed
- Bumped output schema to `1.0.0` in `R/output_contract.R`.
- Added required schema-v1 identifiers:
  - `RunID` (plants + herbivore outputs)
  - `HerbivoreID` (herbivore outputs)
  - `run_id` (manifest)
- Added deterministic run-id generation (`build_run_id()`).
- Added migration helpers in `R/output_migration_v1.R`:
  - `migrate_plants_output_v0_to_v1()`
  - `migrate_herbivore_output_v0_to_v1()`
  - `migrate_output_csv_v0_to_v1()`
- Added migration fixtures under `inst/extdata/migration_v0/`.
- Updated parity fixtures to schema v1 in `inst/extdata/parity/`.
- Added output contract docs in `docs/output_contract_v1.md` and deprecation note in `docs/output_contract_v0.md`.

## Validation
- `tests/testthat/test_output_contract_v0.R` now validates v0 reference + v1 required columns/manifest fields.
- `tests/testthat/test_output_migration_v1.R` migrates real v0 fixtures and validates schema-v1 outputs.
- `tests/testthat/test_parity_outputs.R` passing with updated schema-v1 fixtures.
