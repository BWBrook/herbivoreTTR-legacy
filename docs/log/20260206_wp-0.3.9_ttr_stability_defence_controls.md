# WP-0.3.9 — TTR stability and defence controls

Date: 2026-02-06  
Roadmap item: `WP-0.3.9`

## Scope completed

- Added explicit TTR stability guardrails:
  - `R/ttr_guardrails.R`
  - `assert_ttr_guardrails()` enforces:
    - finite/non-negative TTR pools,
    - absolute pool cap (`TTR_MAX_POOL_ABS`),
    - day-to-day multiplier cap (`TTR_MAX_DAILY_POOL_MULTIPLIER`),
    - defence fraction cap (`TTR_MAX_DEFENCE_FRACTION`),
    - defence semantics/chemistry bounds (`md == bdef`, `cd <= cs`, `nd <= ns`).
- Integrated guardrails into plant daily update:
  - `R/ttr_daily.R`
  - adds per-day guardrail assertion after TTR updates.
- Clarified defence semantics in implementation:
  - `md` mirrors `bdef` each day (single authoritative defence mass representation),
  - `cd/nd` tracked only when defence wiring is enabled; otherwise held at zero.
- Added stress scenario artefact helper:
  - `R/ttr_stress_scenario.R` (`run_ttr_stress_scenario()`).
- Added test coverage for guardrails and stress behaviour:
  - `tests/testthat/test_ttr_stability_guardrails.R`.
- Added/updated docs and decisions:
  - `docs/decisions.md`
  - `docs/architecture.md`
  - `docs/parameter_units_reference.md`
