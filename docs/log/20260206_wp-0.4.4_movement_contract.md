# WP-0.4.4 — Movement contract (torus geometry + disruption probability)

Date: 2026-02-06  
WP: `WP-0.4.4`  
Author: Codex autonomous run

## Summary

Implemented an explicit movement contract with:
- toroidal shortest-path movement routed through a single primitive (`herbivore_move()`),
- configurable target disruption probability (`movement_disruption_prob` / `MOVEMENT_DISRUPTION_PROB`),
- movement-step behavior in `herbivore_step()` that retains a valid target unless disruption occurs.

Added movement-focused scenario artefacts and tests for wrap behavior, step limits, and disruption-driven retargeting.

## Implementation notes

Code changes:
- Added constant:
  - `CONSTANTS$MOVEMENT_DISRUPTION_PROB`
- Added herbivore state field:
  - `movement_disruption_prob` (initialized in `init_herbivore()`)
- Added movement policy helper:
  - `resolve_movement_disruption_prob()`
- Refactored movement in `herbivore_step()`:
  - configurable disruption draw,
  - target persistence while moving,
  - movement updates delegated to `herbivore_move()`.
- Reworked `herbivore_move()`:
  - base-R implementation,
  - explicit toroidal shortest-path deltas,
  - robust handling of invalid/missing targets,
  - per-step distance cap enforcement.

New scenario helper:
- `run_movement_contract_scenario()` writing artefacts to:
  - `artefacts/canonical_runs/movement_contract_v0/`

Pipeline integration:
- `_targets.R` target `movement_contract_bundle_files`.
