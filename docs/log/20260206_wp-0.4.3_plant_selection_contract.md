# WP-0.4.3 — Plant selection contract (tastiness + stochastic choice)

Date: 2026-02-06  
WP: `WP-0.4.3`  
Author: Codex autonomous run

## Summary

Implemented an explicit, test-backed plant-selection contract centered on stochastic weighted choice:
- tastiness scores now combine nutrient mismatch, distance, defence, and size terms,
- hard constraints set candidate weight to zero (outside detection distance, depleted shoot, out-of-reach browse for browser/mixed),
- weighted sampling remains stochastic while deterministic under fixed seed.

Added a focused selection artefact scenario and integrated it into the targets smoke pipeline.

## Implementation notes

Code changes:
- `calc_plant_tastiness()` now enforces documented directional factors and hard zero-probability constraints.
- `pick_a_plant()` now validates dimensions and normalizes robust non-negative weights.
- `select_new_plant()` now reuses the same scoring/sampling contract as `herbivore_step()`.
- Added constants for explicit scoring weights:
  - `TASTINESS_RATIO_WEIGHT`
  - `TASTINESS_DISTANCE_WEIGHT`
  - `TASTINESS_DEFENCE_WEIGHT`
  - `TASTINESS_EPSILON`

New scenario helper:
- `run_selection_contract_scenario()` writes controlled selection artefacts under:
  - `artefacts/canonical_runs/selection_contract_v0/`

Pipeline integration:
- `_targets.R` now includes `selection_contract_bundle_files`.
