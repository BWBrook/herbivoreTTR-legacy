# WP-0.4.2 — Mixed feeder policy validated

Date: 2026-02-06  
WP: `WP-0.4.2`  
Author: Codex autonomous run

## Summary

Implemented an explicit mixed-feeder interpolation policy and validated that mixed outcomes are directionally intermediate between grazer and browser in a controlled three-type scenario.

Policy implementation:
- `MIXED_BROWSER_WEIGHT` controls interpolation between grazer and browser tastiness multipliers.
- Mixed feeders (`herb_type = 2`) now use browse-height reach filtering (same reach gate as browsers).

## Implementation notes

- Added new constant:
  - `CONSTANTS$MIXED_BROWSER_WEIGHT`
- Added mixed interpolation resolution:
  - `resolve_mixed_browser_weight()`
  - mixed branch in `functional_type_preference_multiplier()`
- Added mixed policy state in herbivore initialization:
  - `init_herbivore()` now includes `mixed_browser_weight`
- Updated browse reach filtering:
  - `get_plants_within_range()` now applies browse-height filter to browser + mixed (`herb_type %in% c(1, 2)`).
- Added mixed scenario target in pipeline:
  - `_targets.R` target `mixed_feeder_bundle_files`
