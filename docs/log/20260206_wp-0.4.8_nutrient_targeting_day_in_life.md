# WP-0.4.8 — Nutrient targeting vs energy-only + day-in-life artefact

Date: 2026-02-06  
WP: `WP-0.4.8`  
Author: Codex autonomous run

## Summary

Implemented and validated a reproducible novelty contrast between nutrient-targeting and energy-only foraging objectives.

Delivered components:
- explicit herbivore mode toggle (`foraging_mode`) with contracted values:
  - `nutrient_targeting` (default)
  - `energy_only`
- behavioural wiring so the toggle changes both:
  - plant tastiness nutrient penalty weighting,
  - foraging persistence mismatch sensitivity.
- a controlled paired day-in-life scenario with identical seed/initial conditions and only mode changed.
- canonical artefacts for both modes plus a comparison bundle and narrative report.
