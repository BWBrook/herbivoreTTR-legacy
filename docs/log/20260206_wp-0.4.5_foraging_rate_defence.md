# WP-0.4.5 — Foraging rate and defence handling penalty contract

Date: 2026-02-06  
WP: `WP-0.4.5`  
Author: Codex autonomous run

## Summary

Implemented and validated an explicit foraging-rate contract in which per-minute
intake is constrained by handling time, defence fraction, gut capacity, and
minimum residual biomass.

Key outcomes:
- defence fraction now yields a measurable per-minute intake penalty under
  controlled probes,
- intake cannot remove shoot biomass below `MIN_SHOOT`,
- component-based residual enforcement is robust to `ms`/component drift,
- defence intake is explicitly tracked (`intake_defence_day`).

## Implementation notes

Code changes:
- `herbivore_eat()`:
  - computes available edible biomass from component pools (`bleaf + bstem + bdef`),
  - enforces residual floor against `MIN_SHOOT`,
  - records `intake_defence_day`.

  - `run_foraging_contract_scenario()` (`foraging_contract_v0` artefacts).
- Added tests:
  - defence-intake penalty,
  - capacity/time limiting behavior,
  - residual-floor behavior under `ms` drift,
  - deterministic artefact bundle generation.
- Added targets integration:
  - `_targets.R` target `foraging_contract_bundle_files`.
