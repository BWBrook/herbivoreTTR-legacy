Date: 2026-02-06  
Repo: `herbivoreTTR`

## Scope delivered
- Implemented explicit cross-platform CI posture in `.github/workflows/ci.yml`:
  - `r-cmd-check` now runs as a matrix over:
    - `ubuntu-latest`
    - `macos-latest`
    - `windows-latest`
  - Linux-only system dependency install guarded by `if: runner.os == 'Linux'`.
  - Linux remains the full-gate runner for tests/lint/smoke/coverage.

## Evidence
- CI configuration diff shows matrix-based `R CMD check` on all three OSes.
- Policy recorded in `docs/decisions.md`:
  - "2026-02-06 — Cross-platform CI support policy"

## Verification status
- Local (Linux) package validity and quality gates were re-run and passed.
- Cross-platform execution itself requires GitHub Actions runtime; this session verifies configuration and Linux parity.

## Risk and mitigation
- Risk: OS-specific runner differences surface only in remote CI execution.
- Mitigation: matrix jobs are now mandatory check jobs; failures become visible and blocking in PRs.
